# Nestly Ops

**Simple things for an organized everyday life.**

Internal operating system for Nestly.

> Shopify runs the store. Nestly Ops runs the business.

## Scope

This repo is for everything behind the Nestly business except the Shopify storefront itself:

- Products, pricing and bundles
- Suppliers and fulfillment
- Marketing and growth
- Shopify app experiments
- Customer insights
- Metrics and business decisions
- Operating processes and learnings

## Store

- Primary domain: **mynestly.com**
- Current subdomain: **nestly.blinto.co**
- Commerce platform: **Shopify**
- Model: **Branded dropshipping**
